# C++ Calculator

My first C++ project.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulo (%)
- Division by zero handling
- Modulo validation
- Continue option (y/n)

- User Input
- Basic Error Handling
